# Neoloni Styles (Fabric, MC 1.21.11)
Eigene, komplett offline laufende Style-Mod. Taste K öffnet das Menü, pro Kategorie wählst du einen Style (oder Standard).
Kein Updater, keine Statistik, kein Netzwerkcode.

Eigene Texturen: Unter src/main/resources/resourcepacks/<style>/assets/minecraft/textures/... einfach die PNGs ersetzen.
Neue Styles: Eintrag in NeoloniStyles.java (Liste STYLES) + Ordner unter resourcepacks/ anlegen.
